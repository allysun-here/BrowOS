# Changelog

## Unreleased

- New apps: To-Do, Pomodoro, Weather, Music, Terminal, Recycle Bin, Snake, Minesweeper, Tetris
- Virtual desktops, window snapping, customizable keyboard shortcuts
- Notifications with Do Not Disturb, system tray and quick settings
- Start menu search
- Desktop widgets and sticky notes
- Lock screen with optional PIN, screensaver, theme packs
- Recycle Bin for removed apps and shortcuts
- Export / import backup
- Apps now receive keyboard focus when opened

## 1.0.0

First public beta.

- Desktop with draggable windows, taskbar, Start menu and right-click menus
- Apps: Notepad, Calculator, Clock, Paint, Browser, Task Manager
- BrowStore: Discover, BrowOS Apps, Library, add any website
- Floating windows for sites that can't be embedded
- Personalization: wallpapers, accent color, theme, corners, window buttons, transparency, cursor
- Update reminder for manual installs
